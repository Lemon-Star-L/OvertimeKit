# 加班数据核对工作台｜中文操作手册

**版本：1.0.0** · 作者：YiLong Li

[返回项目说明](../README.md)

## 一、导入与匹配

基础数据表导入加班申请明细，汇总表导入考勤汇总。支持 XLSX、XLS；每侧选择一个工作表，确认表头及字段映射后点击“一键匹配执行”。处理期间显示反馈，完成后跳到异常区。

| 数据来源 | 必需字段 |
| --- | --- |
| 基础数据表 | 员工编码、申请加班小时数、加班补偿方式、加班类型 |
| 汇总表 | 员工编码、加班用于调休、加点时数、周末加班时数、节假日加班时数 |

同员工有效明细累计；原空白时数按 0 比较。工具不自动去重或筛选月份及审批状态。Excel 公式需先计算保存；导入后只读取缓存结果。

## 二、筛选与勾选

异常区可切换仅待确认、仅已确认或全部项目，也可使用全局搜索。在异常列表表头内可按状态、编号、员工编码、Excel 行号、字段、异常原因、原值及计算值进行文本包含匹配，多条件同时满足。

列表每页 20 项。表头复选框只全选当前筛选结果的当前页，不选择其他页。切换筛选后清空勾选；翻页时清除离开当前页的勾选。批量处理栏显示当前选择数量。

点击“查看 / 核对”可进入单项卡片，当前项目在列表中高亮。

## 三、逐项及批量处理

处理说明为选填。逐项可保留原值、采用计算值或输入非负人工时数。非时数类异常使用确认已核查或确认排除等对应操作。

| 批量方式 | 适用范围 |
| --- | --- |
| 保留原值 / 确认已核查 | 时数差异保留原值，其他异常确认已核查；无效明细仍排除在汇总外 |
| 采用计算值 | 仅限具有有效计算值的时数差异 |
| 统一人工时数 | 仅限时数差异，向勾选的每项填入同一个非负小时数 |
| 确认已核查 | 仅限非时数异常 |

点击“处理勾选项”后会提示数量并要求确认。选中项目不适用所选方式时，整批不执行，避免只改动部分项目。已确认项目可在“全部项目”或“仅已确认”下重新处理。

汇总表重复员工编码不自动分配加班总数，只能保留或人工填写。基础数据无效明细若应计入，需修正源表后重新导入；确认排除不会将其加入计算。

## 四、未全部核对时导出

执行匹配后即可点击“导出核对结果 Excel”。如果有未确认项，会提示剩余数量并询问是否继续；取消则不导出。

继续导出时：

- 已确认项按所选处理方式更新。
- 未确认的目标时数保留原值，不自动采用计算值。
- 无效基础明细仍不参与汇总，异常保留在核对记录中。
- 文件名带“未全部核对”，导出说明中记录未完成状态和剩余数量。
- 导出不会将待确认项目自动改为已确认。

结果文件包含核对结果、核对记录、基础数据汇总、未匹配员工及导出说明。导出为值表，不复制源样式、公式、宏和其他工作表。

## 五、浏览器自动缓存

导入、修改映射、执行匹配、单项或批量确认、恢复进度等操作后，自动保存当前两张工作簿、字段配置、匹配结果及已确认记录到本工具的 IndexedDB。底部显示缓存状态，只有事务完成后才显示已缓存。

使用同一浏览器及相同 HTML 路径重新打开时，尝试自动恢复，无需重新选择 Excel。未点击确认的说明草稿、勾选项和筛选条件不保证恢复。等底部显示已缓存再关闭页面。

若缓存被浏览器拒绝、容量不足或无法恢复，可继续导入处理，并使用进度 JSON 备份。移动文件、无痕模式或浏览器清理可能导致缓存不可用。建议只打开一个工作台标签页，避免多个页面相互覆盖缓存。

## 六、清理与备份

| 操作 | 效果 |
| --- | --- |
| 清空工作区 | 清空当前两张表、结果及确认记录，并自动保存空工作区 |
| 清空浏览器缓存 | 删除本工具的持久快照；当前页面保留，下一次数据操作会重新缓存 |
| 保存核对进度 | 下载包含人工确认意见的 JSON 文件，不包含完整 Excel |
| 恢复进度 | 重新导入相同文件并执行匹配后，选择 JSON，校验配置及数据后恢复 |

两种清理操作均会要求确认，不删除源 Excel 或已下载文件，不清理其他网站的数据。


## 按异常原因及字段批量处理

“异常原因”和“字段”提供下拉选项，按本次匹配结果自动生成，选择后精确筛选。其他列继续支持文本包含匹配，多项条件同时生效。

1. 选择异常原因，例如“基础数据无此员工记录”，必要时再选择目标字段。
2. 批处理范围选择“当前页勾选项”，或“全部筛选结果（跨页）”。
3. 选择处理方式，点击执行，核对弹窗中的范围、原因、字段和数量后确认。

“全部筛选结果”遵循状态、搜索及所有字段条件，不受当前页限制；“当前页勾选项”仅处理勾选行。不适用所选处理方式时，整批不执行。默认使用当前页勾选项。


## 表头筛选与时数对比

筛选控件直接位于异常列表的对应表头内；异常原因、字段使用下拉选项，其他列使用文本包含匹配。即使没有符合条件的结果，表头筛选仍保留，可继续修改或重置。

列表和详情卡片展示“汇总表现有值（小时）”“基础表计算值（小时）”及“差值（计算－现有）”。员工级异常按调休、加点、周末、节假日四类逐项展示；单个字段差异只展示对应时数。员工编码仅用于标识员工，不再作为时数原值。

- 基础表未找到该员工记录：四类按 0 汇总，不代表已确认没有加班，仍需核实是否漏导。
- 基础表有记录但没有有效时数：记录已因数值或分类问题排除，应检查无效明细。
- 基础表存在有效及无效记录：计算仅包含有效明细，详情显示总记录数及有效数。
- 重复员工编码、无法定位汇总行等情况不强行计算差值，显示“无法比较”。

核对记录导出同步采用以上对比口径。已确认后的最终值仍按所选处理方式生成；“现有值”始终指输入汇总表中的原始时数。
